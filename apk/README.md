# APK 目录说明

## tiedun/（当前）

铁盾项目的构建产物，与历史包分开存放。

| 目录 | 用途 |
|------|------|
| `tiedun/debug/` | 开发调试构建 |
| `tiedun/stable/` | 稳定构建 |

## legacy-lock-escape/（历史归档）

lock-escape 时期的历史 APK，仅作留档，不再作为推荐下载。

| 目录 | 用途 |
|------|------|
| `legacy-lock-escape/stable/` | 历史稳定构建 |
| `legacy-lock-escape/debug/` | 历史调试构建 |
| `legacy-lock-escape/archive/` | 历史归档 |
| `legacy-lock-escape/_legacy-original-layout/` | 旧文件名别名 |

分发义务见根目录 `LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md`。
