## 简体中文（V2EX / 掘金）

**标题**：lock-escape 锁机逃生 —— 开源 Android 应急逃生工具（半成品，欢迎改）

被锁机病毒 / 无障碍恶意锁屏困住时，连按音量键（或长按音量下）触发全屏 Overlay 拦截，再经 Shizuku / root 把锁机组件 force-stop / disable / uninstall。

- 技术点：无障碍按键监听、TYPE_APPLICATION_OVERLAY 全屏拦截、Shizuku/root 通道、白名单与系统包保护
- 许可：GPL-3.0，附 NOTICE / 第三方声明 / 传递依赖清单
- 定位：**半成品**，骨架可用，欢迎 Fork / PR 继续完善
- 安装包已按 `stable / debug / archive` 分类，Release 可直接下

## English（Reddit r/Android / r/androiddev）

**Title**: lock-escape — open-source Android emergency escape tool (WIP, GPL-3.0)

If a malware/lockscreen app hijacks accessibility and traps you, this tool lets a physical key combo pop a full-screen overlay, then uses Shizuku/root to force-stop / disable / uninstall the lock component.

- Accessibility key listening + overlay intercept + Shizuku/root cleanup
- Whitelist, system-package protection, escape logs
- Explicitly a **half-finished** project — happy to take PRs
- APKs categorized: stable / debug / archive on GitHub Releases
