## 简体中文（V2EX / 掘金）

**标题**：tiedun 铁盾 —— Android 设备防护与应急处理工具

被锁机程序 / 无障碍恶意锁屏困住时，连按音量键（或长按音量下）触发全屏拦截，再经 Shizuku / root 把问题组件 force-stop / disable / uninstall。

- 技术点：无障碍按键监听、TYPE_APPLICATION_OVERLAY 全屏拦截、Shizuku/root 通道、黑名单护盾、白名单与系统包保护

## English（Reddit r/Android / r/androiddev）

**Title**: tiedun — open-source Android device protection & emergency escape tool (GPL-3.0)

If malware or a lockscreen app hijacks accessibility and traps you, this tool lets a physical key combo pop a full-screen UI, then uses Shizuku/root to force-stop / disable / uninstall the offending component.

- Accessibility key listening + full-screen intercept + Shizuku/root cleanup
- Blacklist shield, whitelist & system-package protection, event logs
- Continuous suppression, root monitor, optional accessibility keep-alive (user-controlled)
- PRs welcome
- APKs categorized: stable / debug / archive on GitHub Releases
