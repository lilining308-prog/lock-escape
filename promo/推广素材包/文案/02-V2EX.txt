【社区帖】tiedun 铁盾 · Android 设备防护与应急处理工具

被锁机程序 / 无障碍恶意锁屏困住时：
连按音量键（或长按音量下）→ 全屏拦截界面 → Shizuku/root 把问题组件 force-stop / disable / uninstall。

要点：
· 无障碍按键监听 + 全屏拦截
· Shizuku / root 处理通道（系统包/桌面/输入法保护）
· 黑名单护盾、白名单、持续压制、处理日志
· Root 守护监听 + 无障碍锁定（总开关可关）
· GPL-3.0，附 NOTICE / 第三方声明 / 依赖许可清单
· 欢迎 Fork / PR
