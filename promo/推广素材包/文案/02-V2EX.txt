【社区帖】lock-escape 锁机逃生 · 开源 Android 应急逃生工具

被锁机病毒 / 无障碍恶意锁屏困住时：
连按音量键（或长按音量下）→ 全屏 Overlay 拦截 → Shizuku/root 把锁机组件 force-stop / disable / uninstall。

要点：
· 无障碍按键监听 + 全屏拦截
· Shizuku / root 清除通道（系统包/桌面/输入法保护）
· 白名单、逃生日志、持续压制
· GPL-3.0，附 NOTICE / 第三方声明 / 依赖许可清单
· 定位是半成品，欢迎 Fork / PR
