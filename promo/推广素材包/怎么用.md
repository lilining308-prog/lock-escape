# lock-escape 推广素材包（直接发各平台）

**不要自己的服务器。** 下载统一走 GitHub Release，下面全是「复制文案 + 上传图」就能发的素材。

## 统一链接（每条文案里已写好）

| 用途 | 链接 |
|------|------|
| 仓库 | https://github.com/lilining308-prog/lock-escape |
| Release 分类下载 | https://github.com/lilining308-prog/lock-escape/releases/tag/v2.0 |
| 推荐 APK | https://github.com/lilining308-prog/lock-escape/releases/download/v2.0/lock-escape-v2.0-release.apk |

## 目录

```
推广素材包/
  文案/
    01-X-Twitter.txt      ← 已发过可补 #话题；新发用这份
    02-V2EX.txt
    03-掘金.txt
    04-酷安.txt
    05-Reddit.txt
    06-YouTube简介.txt
  封面/

    cover-square-1080.png      ← 酷安/朋友圈/方图
    card-download.png          ← 突出下载链接
  图/截图/
    01-主界面.png
    02-功能列表.png
```

## 各平台怎么发

| 平台 | 文案 | 配图 |
|------|------|------|
| X / Twitter | `01-X-Twitter.txt` | cover-wide 或主界面截图 |
| V2EX | `02-V2EX.txt` | cover-og + 主界面 |
| 掘金 | `03-掘金.txt` | cover-og + 主界面 + 无障碍 |
| 酷安 | `04-酷安.txt` | cover-square + 主界面 |
| Reddit | `05-Reddit.txt` | cover-wide + main UI |
| YouTube | `06-YouTube简介.txt` | 已有截图 |

## APK 分类（写帖时可提一句）

- **stable**：`lock-escape-v2.0-release.apk`（推荐）
- **debug**：开发测试
- **archive**：0.1.0 历史，不推荐

## 一句话卖点

> 被锁机困住时，按键逃生：全屏拦截 + Shizuku/root 清除锁机组件。开源 GPL-3.0 半成品，欢迎改。
